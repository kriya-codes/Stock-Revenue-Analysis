# 📈 Tesla and GameStop Stock & Revenue Analysis

## 📌 Project Overview

This project focuses on extracting, analyzing, and visualizing historical stock market data and quarterly revenue for **Tesla (TSLA)** and **GameStop (GME)** using Python.

The project demonstrates how financial data can be collected from multiple sources, processed using Python libraries, and visualized to understand stock price movements and company revenue trends.

## 🎯 Project Objectives

- Extract historical stock price data using Python.
- Collect quarterly revenue data through web scraping.
- Clean and process financial datasets using Pandas.
- Analyze historical stock prices and revenue trends.
- Create visualizations to compare stock performance and revenue over time.

## 🛠️ Technologies & Libraries

- **Python** – Main programming language.
- **Jupyter Notebook** – Interactive development environment.
- **yfinance** – Extracting historical stock market data.
- **Pandas** – Data manipulation and analysis.
- **Requests** – Retrieving webpage content.
- **BeautifulSoup** – Web scraping and HTML parsing.
- **Matplotlib** – Creating stock price and revenue visualizations.

## 📊 Project Tasks

### 1. Tesla Stock Data Extraction
- Retrieve historical Tesla stock data using Yahoo Finance.
- Extract stock information using the `TSLA` ticker.
- Store the extracted data in a Pandas DataFrame.

### 2. Tesla Revenue Data Extraction
- Retrieve Tesla quarterly revenue information using web scraping.
- Parse HTML content using BeautifulSoup.
- Clean revenue values by removing dollar signs and commas.

### 3. GameStop Stock Data Extraction
- Retrieve historical GameStop stock data using Yahoo Finance.
- Extract stock information using the `GME` ticker.
- Store the extracted data in a Pandas DataFrame.

### 4. GameStop Revenue Data Extraction
- Retrieve GameStop quarterly revenue information using web scraping.
- Extract the required HTML table.
- Clean and process the revenue dataset.

### 5. Data Visualization
- Visualize Tesla historical stock prices and revenue.
- Visualize GameStop historical stock prices and revenue.
- Compare stock price and quarterly revenue trends through graphs.

## 📈 Visualizations

The project generates visualizations for:

- Tesla historical share prices.
- Tesla quarterly revenue.
- GameStop historical share prices.
- GameStop quarterly revenue.

The notebook's graphing function displays stock price and revenue in separate plots. The visualizations are limited to the historical period specified in the notebook (June 2021 for stock prices and April 2021 for revenue).
